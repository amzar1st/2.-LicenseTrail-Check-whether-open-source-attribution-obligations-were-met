## Overview

LicenseTrail gives release maintainers and reviewers a shared record of whether a release includes the notices required by its declared dependencies. GenLayer validators independently retrieve a commit-pinned manifest, shipped notices, and upstream license files, check SHA-256 commitments, and agree on a structured finding for each dependency under a fixed policy. The dashboard reads finalized findings and links to the exact evidence files. The live Studionet demo includes complete attribution, a missing notice, and conflicting license evidence. Studio’s built-in account signs audit transactions. Reworded upstream notices can be flagged for manual review, and the report is scoped to the declared evidence.
